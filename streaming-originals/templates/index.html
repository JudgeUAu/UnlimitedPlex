Streaming services

TV: uses TMDB's network field — accurate. Movies: TMDB has no "network", so a movie counts as an original if it's from that service's studio (e.g. Netflix, Amazon MGM, Apple Studios, HBO Films). For Disney+/Hulu/Paramount+/Peacock/Prime/Apple the movie must also be currently streaming there. Movies from some services will be incomplete — treat the movie side as best-effort.
